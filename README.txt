# Attendance Dashboard v2.2 (Desktop Version)

Professional attendance processing with CustomTkinter UI.

---

## Quick Start

   Double-click: RUN_APP.bat

---

## Requirements

   pip install customtkinter pandas openpyxl xlsxwriter xlrd

---

## Create EXE

   Double-click: CREATE_EXE.bat
   Find at: dist\AttendanceDashboard.exe

---

## Input Files

1. Master Data (Excel) - Employee PS ID, CRM, Name
2. Attendance Files (Excel) - Daily clock in/out
3. Leave Sheet (Optional) - Leave records

---

## Output (4-Sheet Report)

1. Summary - Color-coded attendance matrix
2. Analytics - Per-employee statistics
3. Alerts - Flagged issues & warnings
4. Penalties - Automated penalty calculations

---

## Keyboard Shortcuts

   Ctrl+M = Select Master
   Ctrl+A = Select Attendance
   Ctrl+L = Select Leave
   Ctrl+G = Generate Report
   Ctrl+R = Clear All
